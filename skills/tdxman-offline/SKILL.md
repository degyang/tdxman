# tdxman-offline

先读 [offline 命令参考](references/offline.md)，确认 vipdoc 路径、标的市场及本地文件更新时间，再执行 `tdxman offline --help` 核对当前选项。此命令不联网、不刷新数据；在线行情用 [tdxman-market](../tdxman-market/SKILL.md)。共用输出规则见 [tdxman-shared](../tdxman-shared/SKILL.md)。
