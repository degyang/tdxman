本轮没有修改 Tick Stock Panel 文件、配置、用户偏好、软链接或进程，也没有调用其 HTTP 服务。
没有覆盖 `src/tdxman/integrations/...` 或 editable 安装引用的适配器，避免文件监听自动重载。

候选改动汇总在 [tdxman 恢复补丁](patches/tdxman-provider-recovery.patch)。
已使用 `git apply --check` 检查它能应用到本项目当前工作区，尚未应用。
后续接入仅允许指向本项目受管资产的软链接或消费端配置；不再向消费端复制业务代码、测试或需求文档。

## 500 的确定根因

日志中的 `KlineRepository._has_minute_parquet()` 调用了不存在的 `self._has_parquet()`。
后者实际属于 `DataStore`，且新增保护在 `try` 外，因此 AttributeError 直接导致 HTTP 500，
请求未到 tdxman。这是此前助手引入的错误；之前将其归因于服务热重载退出的说法没有依据。

[撤销错误保护的补丁](patches/tickflow-revert-minute-guard.patch)仅作为审计记录，未执行。
本轮后续只读检查发现外部已撤销这一改动，当前 `repository.py` 无工作区差异，
因此不要再次应用撤销补丁。没有重启或请求线上接口，不能据此宣称运行中进程已加载新代码。
原先空 Parquet 的 warning 仍可能出现，但原逻辑会返回空表并允许 provider 回退。
插件侧不 monkey patch 消费端仓库以隐藏告警。

## 候选实现

- 恢复统一适配器入口：daily/minute/realtime/depth5/full_minute，清单与 config.datasets 一致。
- 恢复 daily/iter_daily、目录、指定指数、test_dataset、close 和 local/online 配置；默认 online。
- 探活只检查依赖和配置，不联网、不创建本地池；local 模式校验 catalog 存在。
- 分钟复用 `tdxman kline` 的 MAC `get_stock_kline` 端点，不再解析 CLI 子进程输出。
  支持 1/5/15/30/60 分钟及 MIN 拼写，显式 Adjust.NONE，输出市场后缀与上海 naive 时间。
- 股票/ETF 分钟成交量股→手；金额为元，缺失保留 null；稳定八列空表。
- 每页至多 700 根，边界包含、排序去重、无进展/达到上限明确失败，部分证券失败不伪装整批成功。
- 当日分钟只取当前上海日期，按 count 限制请求与返回数量，避免每轮每股取 8000 根。
- 保留全量分钟修复入口。未完成全市场增量成本验收，候选插件 `get_intraday_latest=None`，
  按消费端既有 callable 判断降级为修复轮；原适配器的显式最新 N 根功能仍可独立测试。
- 实时/盘口复用原有字段标准化，报价按最多 80 只分片并验证每批身份；盘口拒绝无限值、负值和缺档。
- 目录按 80 条分页，检测重复/漂移和总量上限。JSON 预览保留证券身份，日期转 ISO，非有限可选值转 null。
- 生产入口使用懒连接及锁串行复用，不跨线程共享未加锁 socket；失败释放连接，最多重试 2 次，指数退避。
  不启动后台线程或心跳。close 幂等，关闭后拒绝请求。
- 每请求 300 秒协作式截止检查；单次 socket 10 秒超时。正在进行的 socket 调用不是硬取消，
  截止检查不能保证正好在 300 秒瞬间终止。收集式返回默认最多 200 万行，大日线范围用迭代接口。
- 日志含独立请求 ID、耗时、分钟请求/实际范围、实时覆盖数量；无共享 last_error。

## 需求核对

| 验收项 | 当前证据与限制 |
| --- | --- |
| A01 证券身份 | 后缀、前缀及显式市场输入；不猜裸代码市场；同码不同市场保持独立 |
| A02/A03 单位 | 原日线/实时报价 fixture 与新增分钟换算测试通过；不以非空作为真实单位证明 |
| A04 时间/频率 | 五周期参数化与带时区边界回归通过 |
| A05 分页 | 标准日线分页、MAC 700 根边界、目录重复页、报价 80 只分片测试通过 |
| A06 local | 原本地股票/ETF/指数及只读行为测试通过；探活不创建池 |
| A07 分钟 | 真 OHLC K线、缺金额 null、空 schema、排序去重、错误隔离测试 |
| A08 指数 | 指定指数实时单样本成功；指数分钟单位未验证，明确拒绝。行业板块在线日线需独立 MAC 单位依据，明确拒绝错误标准路由 |
| A09 时间 | 缺日期不拼今日，非法时间返回未知；真实盘口/指数样本含源时间 |
| A10 五档 | 原字段/别名 fixture、五项顺序、坏档拒绝、真实单证券样本 |
| A11 全市场 | 冻结目录与分片身份检测已实现；本轮未重拉全市场，不重用历史 7304 条记录作为本候选版本证明 |
| A12 错误 | 实时失败 []、指数失败 None、分钟抛错、试拉结构化错误，独立回归通过 |
| A13 资源 | 重连释放、复用、关闭、并发锁、截止与结果量限制有测试；不声称异步或硬取消 |
| A14 全量分钟 | 当日过滤/count/失败语义通过；全市场实际运行成本未验收，高频增量入口未开放 |
| A15 消费协议 | 独立执行消费端实际注册/矩阵函数，五类候选及 usable 均通过；未做运行中服务/UI 联调 |
| A16 非目标 | 不声明 financial/adj_factor，不调用财务或交易功能 |

结论：候选修复与离线契约验证完成，不等于全部生产验收完成。
A08 的未验证单位、A11/A14 的全市场覆盖和成本、A15 的运行中联调仍是发布限制；
不会为恢复选项而把未知单位或未验收性能冒充已支持。
