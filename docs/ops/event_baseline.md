# 全历史复权事件基准

用户指定 ageman 的全历史同花顺事件导出为权威基准。它属于基础数据，
不是累计复权因子。生产位置为 `data/event_baseline.sqlite`；复制基础库时
必须包含该文件。源文件版本、SHA-256、字段单位与覆盖范围在 `metadata` 中。

原始行全部保留，包含同日重复、负送股比例和未来事件；按上海时区解释日期。
旧通达信事件保留为补充及核对证据，不代表新的基准优先级。
不得把两来源的同日分红叠加。完全重复仅能在计算时去重；不同值冲突需要
明确选择依据。未来事件仅在其生效后参与对应日期计算。

读取基础事件使用 `aspool.event_baseline.read_events(root, symbol=..., start=..., end=...)`。
查询按股票和日期索引定位，返回原始字段及行号，不自动合并事件。
每股分红、送股、配股比例已经按每股计量，不能再次除以 10。

基准已入库并逐行核验，现有 `adjustments.sqlite.stock_adjustment_factors`
已按新基准重建，来源为 `derived:baseline_event_chain`。使用最早有效行情日
归一化为 1，区间截至指定计算日；不伪造更早、缺少行情期间的绝对因子。
现金、送股、配股按每股单位计算；缩股保留负比例；停牌期间连续事件顺序计算。
同日完全相同事件去重，竞争字段必须核验后才能合并，核验记录保存在执行报告中。

重建工具：`python -m aspool.baseline_factors --root data
--report-dir .local/reports/event-baseline --through 2026-09-30 --apply`。
省略 `--apply` 仅预计算；该入口目前要求处于已安全暂停的历史维护状态。
重复执行对相同因子跳过写入。原始行情按股票、日期主键定位，禁止逐事件全表扫描。

元数据 `factor_status=rebuilt` 表示因子已经切换；
`enriched_status=dependent_features_require_rebuild` 表示依赖因子的其它指标
尚未重算。增量同步入口也须对接该基准，不能宣称全链路已切换。
2016—2021 修补任务已按用户要求恢复，使用基准事件重算参考价及涨跌停。
事件库存仅加载一次，按股票和日期定位；重复或冲突事件无法直接确定时保留
行情配对核验路径。通用价格刷新不得重新选回旧累计因子锚点。
原始行情修补结束后重新校验基准因子；其它依赖指标未重建时继续保留维护门禁。

用户指定将 `301660.SZ`、`920162.BJ`、`920196.BJ` 置为无效代码。
目录中设为 `active=false`，`data/invalid-securities.json` 保留人工排除原因，
防止刷新源端目录时自动恢复。默认采集、补缺、状态修补及因子重建跳过这些代码；
原始事件及已有行情不删除。复制基础数据时也包含这一配置文件。
