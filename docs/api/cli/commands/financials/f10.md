# `tdxman f10`

```bash
tdxman f10 600519.SH --section profile --format table
tdxman f10 600519.SH --section report --report-type zcfzb --format json --output output/600519-report.json
tdxman f10 600519.SH --section business --format json
```

`--section` 默认 `profile`；可选 `profile`、`report`、`business`、`dividends`、`shareholders`、`topics`、`announcements`、`news`、`governance`、`forecast`。`--report-type` 默认 `zcfzb`，只影响 `report`；`--report-date` 只允许在 `business`，不传时先从服务端查最新可用报告期；显式指定时应沿用该服务返回的报告期字符串。`--timeout` 默认 8 秒，最小 0.1 秒。此命令有 `--format`/`--output`，没有 `--fields`。

CLI 使用独立 7615/TQLEX 的 `F10Client.query(market, code, section, report_type, report_date)`，查询前用服务端 `gpquery` 核对市场和代码。结果展开为记录数组，包含 `symbol`、`entry` 和 `result_set`，各栏目的列可不同；按 `result_set` 区分表。它不等同于标准协议 `get_company_info_content`，也不保证历史时点完整快照。`--report-type` 的服务端可用值以目标查询和当前帮助/返回为准。CLI：`src/tdxman/cli/cmd_f10.py`；API：`src/tdxman/f10.py#F10Client`；语义：[项目 README](../../../../../README.md)「财务」。
