# 近五年涨跌停与连板修复（2026-09-24）

目标区间为 2021-09-24 至 2026-09-24；生产根目录为 `/home/ubuntu/.aspool`。
任务补证券日期事实、参考价依据、量价指标和限价派生，不重新回填全量 OHLCV。
后续 v6 修复中，`302132.SZ` 的 891 日历史价格经双源核对后定向更正；
成交量、成交额以及其他证券的 OHLCV 不变，详见本文件后续结果与字段审计报告。

## 根因

1. 原始日线已有多年数据，限价发布指针仅有 15 个日期；历史派生从未完整生成。
2. 历史导入含混合价格口径。例如 600519 在 2021-09-24 的原始收盘价为 1694，
   存储的 `pre_close` 为 1446.62，直接使用会误报涨停。
3. `stock-sync` 能补历史 K 线，但这些行不一定带 `pre_close` 和 `is_st`。
   报价 `update` 只取得当日报价；9 月 24 日补入的 22、23 日 K 线缺少参考价，
   随后的当日报价更新没有修复这两天，形成连板递推断点。
4. 原规则未覆盖 2023 年注册制前主板普通交易日；逐证券逐行 SQL 发布也不适合五年重算。

## 修复口径

- `cn-a-share-limit-v5` 支持已能排除首日的历史主板常规限幅。
  [上交所历史首日规则](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988762.shtml)、
  [深交所历史首日规则](https://www.szse.cn/www/disclosure/notice/company/t20140613_508770.html)。
- 2026-07-06 起主板 ST 限幅调整为 10%；此前需当日 ST 依据区分 5%/10%。
  [上交所修订通知](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)、
  [深交所实施通知](https://www.szse.cn/lawrules/service/member/t20260630_621404.html)。
- 当日涨跌幅采用保守的两位小数误差区间，不把显示的小数位数当成真实精度。
  对原参考价缺失或冲突的行，只有区间内存在唯一分币参考价才恢复；若同时等于
  上一市场会话的收盘价，依据记为 `previous_session_close_confirmed_by_return`。
  除权日不能直接使用上一行收盘价，多解或无解保留未知。
- 317 只存在无法唯一恢复参考价的股票定向查询 BaoStock 五年数据；其他沪深股票
  只补近期断点日期。写入日期事实前比对未复权 OHLC，冲突不采用其参考价。
- 日期事实保存在 `security_daily_facts`；上市退出日期及交易日历另表保存。
  原始 OHLCV 不改写。公开 `read_daily/read_research_daily` 叠加日期事实及已发布的
  参考价修正，并返回 `pre_close_source`；参考价冲突且派生已陈旧时返回未知。
- 连板按完整市场会话连续递推；可靠停牌暂停计数，无行情不能直接当成停牌。
  默认额外计算 120 个自然日的前史；尚未找到可靠边界的连板仍为 null。
- 每日范围、事件、异常、参考价证据批量写入同一事务，与发布指针一起切换。

## 运行与验收

```bash
python scripts/rebuild_limit_history.py \
  --root ~/.aspool --start 2021-09-24 --end 2026-09-24
```

输出位于 `~/.aspool/reports/limit-history/<UTC时间>/`：目录库备份、运行日志、
summary/coverage CSV 与 Parquet、events/exceptions Parquet、连板覆盖 CSV、参考价证据
Parquet，以及 `report.json`。报告核对交易日历完整性、范围计数、发布批次一致性、
stale 状态及原始日线文件是否未变。

公开接口：`DataPool.read_limit_summary/read_limit_events/read_limit_coverage`，以及
`read_limit_references(start=..., end=..., symbols=...)`。最后一个接口用于追溯参考价
修正和未解决冲突，不把数学恢复的依据标记为交易所直接提供。

历史范围仍以池中已保存的股票为准，不能宣称历史全市场证券维表已完备。
BaoStock 不覆盖北交所，剩余未知和异常必须随覆盖报告一起消费。

## v7：用户指定的跨缺行连板口径（2026-09-25）

用户指定：缺口前连板数 + 缺口后连板数，缺口会话不计天数。
实现范围是“缺行前有已知正连板，缺行后继续涨停”。缺行日自身仍留在异常表，
其交易状态不被推断为停牌；后续涨停事件增加 `consecutive_gap_sessions` 记录跳过会话数。
当日明确非涨停则归零；没有可靠前段连板、价格异常、规则未知仍保留未知。

规则版本升为 `cn-a-share-limit-v7`。日常 sync 及全量重算共用同一算法，缺行时的
连板承接状态与当天发布事务一起落库，使后续增量同步可以接续。
这是用户指定的统计口径，跨缺行的连续性由假设建立；事件字段和汇总说明保留这一依据。
