## 状态原则和代码

[证券逐日状态契约](../design/security_daily_state_contract.md) 明确证券＋交易日键，区分成交事实、计算输入分类、指标适用性和发布就绪；不允许用统计 `NO_TRADE` 推断停牌。

整改包括：

1. MAC 部分返回中的缺日期改为 `MISSING`，不再自动写 `NO_TRADE`；已有行情/明确状态保留。
2. 超时、空返回、不支持和无效响应不覆盖已有成交或明确无交易事实；错误和本次覆盖不足继续报告。
3. 空状态规范化仅在有效行情、原分类为 `TRADED`、消费者样本选择等价时执行。每证券最多 5000 条输入、最多 25000 条发布变化。
4. 规范化仅写 `features.sqlite`，逐条校验数值字段和交易分类不变；写入守卫禁止改行情、因子、数值指标和其他 WAL 文件。已有缺因子继续缺失。
5. 本地推断状态不导出为基础来源事实；基础增量接收后的有效交易行情会补本地状态。
6. 证券和市场发布戳维护结束后统一收口；计算输入不变的板块结果复用，真实行情变化则重算板块。

工具：`python -m aspool.sqlite_state_audit`，亦可运行 `scripts/ops/audit_repair_daily_states.py`。提供只读检查、创建并验证恢复点、修补、源端补取、幂等续修与全窗口复查。
