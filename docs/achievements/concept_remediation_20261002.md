## 已交付的公开签名与兼容性

```python
DataPool.read_board_members(
    *, snapshot_id, kind, board_ids, limit=100000, offset=0
)
MacClient.get_minute_bars(
    market, code, *, date, since=None,
    max_pages=4, page_size=240, asset_type="stock"
)
# AsyncMacClient 同参数，需 await。
```

成员入口限定 concept/industry、1—128 个明确板块及最多 100000 条关系；返回总成员数、分页位置、快照依据与采集时间。snapshot_id 不存在、板块不存在、预算或数据非法均明确失败，不自动换成当前快照。它只读取现有来源快照，不需要网络或 schema 迁移。

分钟 date 支持 ISO 日期或 YYYYMMDD；since 为请求日期内上海本地时间，**包含起点**，可留修订重叠。max_pages 限 1—16、page_size 限 1—700。attrs 提供实际起止、源窗口、页请求数、预算是否耗尽；请求数为页派发数，不含运输层重试。源端最新窗口不足以到达目标日期时返回实际覆盖/预算，不推断停牌或补分钟。

旧行情接口参数和原有字段保留；分时新增 date/pre_close/datetime，财务新增两个日期字段和语义元数据。复权数据属于基础输入，本地复权因子、同日股本推导市值属于 Enriched，见[分层契约](../design/data_layers.md)。本次没有迁移生产 schema、写生产数据库、自动回填旧历史或安装进 Fundwise 环境。

## 真实样本与调用成本

[样本 JSON](../evidence/concept-remediation-20261002/samples.json)及[可复跑探针](../evidence/concept-remediation-20261002/live_probe.py)保存签名、字段、覆盖与耗时；探针仅作有限只读请求。实测：

- 种业880710与水产品880903固定快照：25条关系、24只去重股票，完整读取；不是实时历史成分重建。
- GN目录269项；报价排名请求80/81严格返回80/81，81结果前80与80请求保持同序。
- 880710.SH 2026-09-30全天240分钟，09:31—15:00，2页请求（含前一日边界）；14:45起点、page_size=20返回16条，1页请求。
- 600519.SH 2026-09-01及09-30历史分时各240条，返回头日期验证通过；合成协议fixture验证历史头昨收10不会被最新尾昨收90替换。
- 两股来源报价均有同日总/流通股本，完整性与请求字段检查通过；日线落库、单位转换、市值计算及幂等用隔离数据验证，生产旧空值没有被改写。

这些是休市后的有界样本，未验证盘中移动页、封口重订、最远历史或全市场全日期覆盖。SDK 能有界读取尾部，不等于 Fundwise 已改成增量采集。现有每概念最多240根刷新行为的成本仍需按实际链路核算，**192批/日仅是概念报价预算**，不能外推全天链路。
