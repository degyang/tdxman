## 已实现
- limit_events 不在全市场保留历史 Python 字典。第一遍分批仅读日期构造市场日期并集；逐日计算期间按年逐股加载并缓存紧凑 Arrow 行情窗口，只保留当年结果。沿用原递推、前史计数、发布与 stale 口径，不截断上市观测依据。
- 默认内存占用由全部股票历史降为当年全市场窗口、市场日期轴和单日输出。可用
  `cache_years` 扩大紧凑 Arrow 窗口；五年任务在可用内存充足时使用六个自然年度，
  避免重复扫描历史文件，仍不保留全市场历史 Python 字典。运行脚本记录峰值 RSS 与耗时。
- 报价写入完成、派生前持久化deriving维护报告，硬退出后可定位已经完成的原始阶段。原始写入自身阶段的硬退出恢复不在本次新增保证内。
- 仅成功写入的报价日期进入派生。无内容变化但成功处理仍能补算未发布结果。缺标的/派生失败纳入partial并使入口报错，原始写入保留。
- 当前名称ST只接受服务器日期等于本次北京时间日期的报价；早于池尾仍为stale_quote，其余非当日报价为quote_name_date_unconfirmed。非交易日读取上一交易日报价会被拒绝，需单独可靠名称日期依据才能放开。
- 同步重试在换连接前关闭旧连接，维护有锁的活动连接清单；单线程30次失败最多一条活动连接，结束全部关闭。
