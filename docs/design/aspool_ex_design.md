# aspool `ex` 扩展资产域设计

## 目标

`ex` 是跨市场数据域，用来承载不能直接套用 A 股股票或指数契约的资产。它为 Fundwise 的联动策略预留统一的类别、单位和历史起始日期，避免把港股、美股、期货和 ETF 混入同一张股票或指数表。

当前交付第一类是 `ETF`。ETF 是上市基金证券，使用股票式 OHLCV、成交额和换手率字段；它不具备指数的上涨/下跌家数字段。港股、美股和大宗期货已经登记类别，但尚未写入数据池。

## 类别注册表

类别定义位于 `settings/ex_assets.json`，每项包含：

- `code`：稳定的消费端类别代码；
- `source`：tdxman MAC 扩展市场或 A 股分类来源；
- `asset_kind`：`security`、`index` 或 `futures`；
- `history_start`：首次建库允许的最早日期；
- 价格、成交量和金额单位；
- `status`：`implemented` 或 `planned`。

当前计划类别包括港股主板、港股创业板、港股通、美国股票，以及中金所、上期所、大商所、郑商所和广期所商品期货。期货不与股票共用复权、换手率或公司基本面字段；正式接入时还需要合约生命周期、主连/连续合约规则和结算价字段。

## 命令

查看类别及交付状态：

```bash
aspool ex categories
```

同步已交付的 ETF：

```bash
aspool sync --type ex --category ETF --source tdx --period daily
```

`--type etf` 仍作为兼容入口。规划中的类别会明确拒绝同步，不会误把港股、美股或期货写入 ETF 文件。

## 后续接入顺序

1. 港股主板和港股通：先建立商品清单、港币字段和停牌/除牌处理；
2. 美国股票：加入交易所时区、美元字段和夜盘日期归属；
3. 大宗期货：加入合约到期、主力连续映射、结算价、持仓量和夜盘交易日规则；
4. 联动策略 API：提供类别过滤、跨市场日期对齐和明确的缺失值策略。

在这些契约完成前，`DataPool.describe()` 只把类别标记为 `planned`，Fundwise 不应把它们当作可回测数据源。
