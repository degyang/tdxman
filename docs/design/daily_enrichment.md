# sync 的日线字段补齐与派生顺序

股票日线 `aspool sync` 默认执行：主源 K 线同步 → 通达信权息与股本资料补齐 →
量价字段计算 → BaoStock 冲突样本只读校对 → 涨跌停和连板重算。
指数、ETF、分钟线保持各自原有同步路径。

```bash
# 日常同步：默认补齐最近 30 个交易日
aspool sync

# 已有五年 K 线，只补相关字段和派生
aspool sync --enrich-only --start 2021-09-24 --end 2026-09-24

# 关闭冲突样本的外部校对，继续使用已有日期事实和通达信资料
aspool sync --enrich-only --no-baostock --start 2021-09-24 --end 2026-09-24

# 导出已发布五年结果，不重复计算
python scripts/rebuild_limit_history.py --start 2021-09-24 --end 2026-09-24 --export-only
```

`--start/--end` 指字段补齐窗口；`--enrich-only` 跳过主源 K 线同步。
`--no-enrich` 关闭新增权息、股本及指标阶段；BaoStock 开关单独控制。
默认流程的 BaoStock 用途是校对算法和定位价格口径问题；校对结果记录在
`algorithm_check` 中。需要明确执行补源导入时仍可使用 `--source baostock`。
`--limit` 限制补齐证券数，涨停统计仍按完整股票池重新计算，不把抽样统计当成全市场。

## 计算和证据

| 字段 | 依据 | 未能确认时 |
|---|---|---|
| pre_close | 已验证的当日来源值，或相邻市场会话未复权 close 与当日权息事件；统一到价格最小单位后计算 | 缺行、复杂缩扩股、多个权息事件及价格口径异常保留未知 |
| vol_ratio | 当日成交量 / 前五个市场交易日均量，不含当日；明确停牌日按零成交量 | 缺失会话不跳过，不能以最近五行代替 |
| float_share / total_share | 通达信日期股本变动记录；最新 finance 仅用于抓取当日 | 无日期股本锚点、未解决的送转配或缩扩股不沿用旧股本 |
| turnover_rate | 成交股数 / 当日流通股数 × 100；保留有来源标识的 BaoStock 换手率 | 不用今天的流通股数反填历史 |
| float_mv / total_mv | 当日未复权收盘价 × 当日对应股本 | 日期股本未知则为空 |
| pct_chg / amplitude | 当日 close、high、low 与已恢复 pre_close | 参考价未知则为空 |

量比是明确的收盘口径，不能代替盘中某一时刻量比。前五日包含停牌的口径显式固定，
不承诺与每家行情软件完全相同。股本接口记录是事后历史资料，不承诺当时可得性。
历史 PE/PB 需要对应时期的财务与披露依据，本阶段不使用最新 EPS、净资产反填五年估值。

通达信原始输入缓存：`lake/fundamentals/dated_inputs/<代码.市场>.json`，包含权息事件、
最新财务摘要及获取日期。同日重跑复用缓存；次日更新。库中已有的低精度累计复权因子
不直接作为精确涨跌停参考价，本阶段使用按日期生效的权息事件计算。

补值与更新值保存 `*_source`，由公开 `read_daily/read_research_daily` 返回。
报告位于 `reports/maintenance/enrichment-<id>.json`，包括逐证券变化、缺失数、冲突、
源调用失败和派生重算结果；最新索引为 `enrichment-latest.json`。
`status=ok` 表示阶段执行成功，字段完整性仍须检查 `missing` 及涨停覆盖报告。

写入只修改可选字段，逐文件核对日期与 OHLCV 完全未变后原子替换。
参考价修复期间派生标记 stale；全部字段阶段结束后顺序重算受影响日期及后续连板。
源调用失败不伪造权息或股本；局部失败记录报告并使 CLI 非零退出，已成功数据保留。

## v2 算法修复与 v6 限价规则版本

- 参考价校验与返回使用同一个分币值；`2.835` 被确认对应 `2.84` 时，
  后续收益计算也使用 `2.84`。修复先按舍入值校验、再返回原数造成的重复运行漂移。
- OHLC 必须符合股票分币价格精度，允许 float32 传输误差；明显不符合的历史价格
  先记录口径异常，不把其涨跌幅用于反推交易所参考价。
- 涨跌幅是计算输出。旧值或本地重算值不能否决有效的前一会话收盘价及权息依据。
- 合并行情时，输入发生变化会使相关收益、振幅、换手率、市值和量比失效。
  成交量修复或历史缺行补入还会影响后续五个记录的量比；字段阶段按市场日历重算。
- `302132.SZ` 已通过通达信未复权日线与 BaoStock 双源核对，定向修复 891 日的
  历史价格口径错误，成交量与成交额未修改。原文件保存在生产报告目录的备份中。
- 通达信空代码、全零财务响应不能证明“没有权息事件”；此类响应拒绝用于参考价
  计算。`300114.SZ` 的两个除息日已恢复到历史收益校验的参考价，BaoStock 只读
  比较均一致；未获得有效日期股本资料的换手率、市值继续保留未知。

## 本轮生产覆盖

区间 2021-09-24 至 2026-09-24，共 6,229,523 条池内股票日线：

| 字段 | 有效行数 | 缺失行数 | 覆盖率 |
|---|---:|---:|---:|
| pre_close、涨跌幅、振幅 | 6,229,452 | 71 | 99.99886% |
| 收盘量比 | 6,213,888 | 15,635 | 99.74902% |
| 换手率、流通/总股本、流通/总市值 | 6,228,374 | 1,149 | 99.98156% |

分母是池内已有股票日线，不代表历史全市场证券范围已经完整。
71 条参考价缺失中，70 条与通达信上市日期一致；另 1 条是 `920116.BJ` 的
2025-04-18，尚无可靠参考价依据。完整年度分解及字段来源见生产目录中的
`field_coverage.csv`、`validation.json`。
全文件对比确认：原始行情的变动仅为已核对的 `302132.SZ` 891 日 OHLC，
没有其他证券价格、日期轴、成交量或成交额变动。

2026-09-25 起，sync 的限价阶段使用 v8 连板口径：保留 v7 的前段已知连板跨缺行
继续累计，缺行会话不计天数，并输出 `consecutive_gap_sessions`；另将已确认的
旧主板 IPO 首日排除在连板计数之外，后续首个已确认涨停从 1 板计数。
首日特殊限价事件仍保留未知，边界随发布事务持久化。详见
[连板跨缺行口径](../design/aspool_api.md#8-连板跨缺行口径v7)及
[旧主板 IPO 首日口径](../design/aspool_api.md#10-旧主板-ipo-首日的连板计数v8)。
